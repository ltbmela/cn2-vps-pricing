## CN2 GT 和 CN2 GIA 到底差在哪

CN2 GIA 是全程走电信精品骨干网的线路，CN2 GT 只走一部分。这个区别直接决定晚高峰的体验。

- **CN2 GIA**：去程和回程全程走电信 CN2（AS4809），路由节点以 59.43 开头，几乎不绕路。搬瓦工的 GIA-E 套餐不只优化电信——电信走 CN2 GIA、移动走 CMIN2、联通走 Premium（AS10099），三网回程各有对应优化。
- **CN2 GT**：只有部分路段走 CN2，其余走普通 163 骨干网。比纯国际线路好，但晚高峰波动更明显。
- **普通线路**：KVM 常规套餐走的 163/AS4837 等，国内访问质量看运气。

判断方法很直接：同一晚同一地点 ping 和丢包对比，GIA 的路由全程 59.43 开头。买之前认准套餐系列名称，别看机房在洛杉矶就默认是 GIA——搬瓦工洛杉矶既有 GIA 机房也有普通机房。
